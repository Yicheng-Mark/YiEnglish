## ✨ 产品定位

覆盖 **输入 → 理解 → 训练 → 应用 → 反馈** 完整学习链路。打字练习建立肌肉记忆，分级阅读和真实语料接触活的英语，AI 助手随时答疑，科学方法指导节奏。

## 🚀 功能一览

### 📝 打字背单词
- **23 本精准词库**：覆盖中学、大学、英专、留学、考研、专业英语六大类，25 词/章科学切分
- **沉浸式打字**：逐字输入，实时纠错高亮，肌肉记忆 + 视觉记忆双通道强化
- **机械键盘音效**：Web Audio API 合成真实机械键盘声，沉浸式打字体验
- **SM-2 间隔重复**：基于记忆曲线智能安排复习，遗忘前精准召回
- **错词智能分类**：自动识别双字母遗漏、元音混淆、相邻键误触等错误类型
- **听写模式**：隐藏单词，纯靠记忆和中文释义拼写
- **可配重复次数**：1 / 3 / 5 / 8 / 无限次，按需强化
- **跨词库搜词**：全局搜索，点击直达对应词库章节
- **收藏与同步**：支持词汇收藏和词库收藏，登录后跨设备同步

### 📖 分级阅读
- **点击查词**：即点即查，支持不规则动词、复数、时态等 170+ 词形还原
- **生词收藏**：一键收藏至阅读词本，可在打字模块中专项练习
- **沉浸式阅读**：段落级中文翻译折叠，阅读进度持久化
- **多维筛选**：分类、年份、搜索、收藏四维过滤

### 🎬 视频语料
- **11 部精选视频**：TED 演讲、旅行 Vlog、生活播客，美音英音兼备
- **8 种字幕模式**：中英双语 · 纯英文 · 纯中文 · 完形填空 · 听写模式 · 阅读模式 · 中英互译 · 词汇卡片
- **键盘快捷键**：空格暂停 / ←→ 跳转 5s / ↑↓ 切换字幕 / L 循环
- **字幕点词即查**：点击字幕中任意单词，即时查义并收藏
- **移动端专属播放器**：针对触屏优化的手势操作和布局

### 📐 语法体系
- **三阶进阶**：词性 → 时态 → 长难句，由词到句逐步构建语法框架
- **八大词性**系统讲解 · **16 种时态**体系梳理 · **长难句**层层拆分

### 💡 科学学习方法
- 6 大高效学习法，按证据等级分级，附科学方法 vs 低效方法对比数据
- 每日 15-20 分钟最小有效剂量学习计划

### 🤖 AI 助手
- **流式对话**：DeepSeek API + SSE 实时流式回复，支持深度推理过程展示
- **可拖拽悬浮入口**：随时唤起，打字中自动关联当前单词上下文
- **4 种人设**：严肃老师 / 活泼伙伴 / 温柔学长 / 自定义（名称、性别、提示词）
- **长期记忆**：自动提取偏好与学习上下文，跨会话保持连贯
- **快捷指令**：单词释义、例句用法、近义词辨析、记忆技巧一键触达

### 👥 用户系统
- **邮箱注册/登录**：验证码验证，JWT + HttpOnly Cookie 双重鉴权
- **跨设备进度同步**：词库进度、词本、收藏状态服务端持久化
- **个人资料**：昵称、签名、头像、每日学习目标

### 📊 数据统计
- **模块化计时**：打字 / 阅读 / 语料独立计时
- **月度热力图**：学习日历一目了然
- **7 天趋势图**：学习节奏可视化
- **实时追踪**：WPM、正确率、输入数
