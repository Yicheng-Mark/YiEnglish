## ✨ 产品定位

覆盖 **输入 → 理解 → 训练 → 应用 → 反馈** 完整学习链路的英语学习平台。通过打字练习建立肌肉记忆，在分级阅读和真实语料中接触活的英语，用 AI 助手随时解答疑问，用科学方法指导学习节奏。

---

## 🚀 功能一览

### 📝 打字背单词
- **23 本精准词库**：覆盖中学、大学、英专、留学、考研、专业英语六大类
- **科学分章**：每章 25 词，学习负担可控
- **沉浸式打字**：边打边记，肌肉记忆 + 视觉记忆双通道，Web Audio API 合成机械键盘音效
- **SM-2 间隔重复**：基于记忆曲线智能安排复习
- **错词自动收录**：拼写错误自动进入错题本，专项练习
- **跨词库搜词**：全局搜索，点击直达对应词库章节
- **收藏与分类**：支持词汇收藏和词库收藏，数据跨设备同步

### 📖 分级阅读
- 分级文章列表 + 沉浸式文章详情阅读
- **点击查词**：即点即查，加载全部词库构建查词映射，不打断阅读节奏
- **生词收藏**：一键收藏至阅读词本，可在打字模块中专项练习
- 分类、年份、搜索、收藏多维筛选
- 段落级中文翻译折叠，阅读进度持久化

### 🎬 视频语料
- **11 部精选视频**：TED 演讲、旅行 Vlog、生活播客等，美音英音兼备
- **8 种字幕模式**：中英双语 · 纯英文 · 纯中文 · 完形填空 · 听写模式 · 阅读模式 · 中英互译 · 词汇卡片
- **键盘快捷键**：`空格` 暂停 / `←→` 前后跳转 5s / `↑↓` 切换字幕 / `L` 循环
- 字幕点词即查，收藏至语料词本

### 📐 语法体系
- **三阶进阶**：词性 → 时态 → 长难句分析，由词到句逐步构建语法框架
- 八大词性系统讲解，理解句子组成逻辑
- 16 种时态体系化梳理
- 长难句层层拆分，攻克复杂句

### 💡 科学学习方法
- 基于认知科学研究的 6 大高效学习法，按证据等级分级
- **科学方法 vs 低效方法**对比数据
- **每日 15-20 分钟科学记忆流程**，最小有效剂量学习计划

### 🤖 AI 助手
- **流式对话**：基于 DeepSeek API，SSE 实时流式回复，支持深度推理过程展示
- **可拖拽悬浮入口**：随时唤起 AI 对话，打字练习中自动关联当前单词上下文
- **长期记忆**：自动提取用户偏好与学习上下文，跨会话保持连贯
- **4 种人设**：严肃 / 活泼 / 温柔 / 自定义（支持配置名称、性别和提示词）
- **专属页面**：支持从悬浮窗展开至全屏 AI 对话页

### 👥 用户系统
- **邮箱注册 / 登录**：验证码邮件验证，JWT + HttpOnly Cookie 双重鉴权
- **跨设备进度同步**：词库学习进度、词本数据、收藏状态服务端持久化
- **个人资料管理**：昵称、签名、头像、每日学习目标

### 📊 数据统计
- 模块化计时：打字 / 阅读 / 语料独立计时
- 月度学习日历热力图
- 最近 7 天学习节奏图表
- 实时 WPM、正确率、输入数追踪
